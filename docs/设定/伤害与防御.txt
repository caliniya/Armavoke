伤害类型
-热能伤害
对护甲伤害*150%，对护盾伤害*75%
-动能伤害
基础伤害倍率*100%，可以造成击退
-能量伤害
对护盾伤害*130%，对护甲伤害*100%
-特殊伤害
无视伤害类型减免

伤害抗性
通过安装插件，护甲可以具有伤害抗性，对对应类型的伤害获得百分比减免。
插件-冲击装甲模块
使战舰获得动能伤害抗性与击退抗性，提高护甲抗性
插件-热熔装甲模块
使战舰获得热能伤害，增加战舰散热速率，在吸收伤害的同时可以少量恢复能量
插件-能量吸收模块
使战舰获得能量伤害抗性(护甲)，吸收能量伤害时可以恢复能量
插件-护甲结构模块
提升战舰的护甲强度

护盾抗性调整
通过安装模组并激活，护盾可以在受到攻击时调整伤害抗性
模组-适应性护盾力场
激活后持续消耗一定能量，使护盾对特定伤害类型具有百分比抗性(具体取决于模组类型)
模组-反应式护盾力场
消耗少量能量激活，期间护盾受到伤害后对伤害量最高的伤害类型的抗性提升(具体倍率取决于模组)(提升的前提是护盾对此伤害类型具有抗性，伤害类型对护盾的伤害比例不算护盾的伤害抗性)
模组-能量吸收系统
激活后持续消耗能量，护盾对能量伤害具有抗性，减免能量伤害时可少量战舰的能量水平
模组-强化性护盾力场
消耗能量激活，激活后，护盾强度获得提升

伤害机制
-计算能量武器的衰减和弹药武器的命中率
-作用于护盾，计算穿透量，随后依据护盾抗性限制得出实际穿透量
-使用护盾的伤害乘以护盾的伤害抗性，再乘以护盾强度的倒数(两者均为独立乘区)，得出实际伤害并应用 
-计算对护甲的穿透，并使用护甲强度限制穿透量
-使用护甲的伤害抗性(百分比减免)和护甲强度(数值减法)减免伤害并应用(先使用护甲的伤害抗性乘算，再进行护甲强度减算)
-作用于核心，使用核心抗性计算实际伤害量(使用武器穿甲指数计算穿透，穿透的伤害消失，对核心伤害比例不低于百分之5(过穿))

[伤害公式]
D = 有效伤害
P_s = 穿透指数（对护盾）
P_a = 穿甲指数（对护甲/核心）
M_s = 破盾指数
M_a = 破甲指数

K_s = 对护盾伤害类型倍率
  - 热能：0.75
  - 动能：1.0
  - 能量：1.3
  - 特殊：1.0

K_a = 对护甲伤害类型倍率
  - 热能：1.5
  - 动能：1.0
  - 能量：1.0
  - 特殊：1.0

S_cap = 护盾当前容量
R_pen_s = 护盾穿透抗性
R_min_s = 护盾抗性（最低承受伤害比例(无聊穿透指数多高，护盾至少承受此比例伤害)，大多数战舰为0）
I_s = 护盾强度（倒数乘区，护盾容量为0时强度为0，此时护盾层不再参与计算）
R_type_s = 护盾伤害抗性（来自模组，无则为0）

A_cap = 护甲当前容量
R_pen_a = 护甲穿甲抗性
R_min_a = 护甲抗性（最低承受伤害比例，大多数战舰为0）
I_a = 护甲强度（数值减法）
R_type_a = 护甲伤害抗性（来自插件，无则为0）

C_cap = 核心当前容量
R_core = 核心抗性

-溢出规则
击碎护盾的一次攻击不会将溢出伤害传递至护甲，护甲同理不溢出至核心。

-穿盾量
D_past_shield = D * min((1- R_min_s), min(1, max(0, (P_s - R_pen_s) / R_pen_s)) ) 

-对护盾实际伤害量
D_to_shield = (D - D_past_shield) * M_s * K_s

-穿甲量
D_past_armor = D_past_shield × min( (1 - R_min_a), min(1, max(0, (P_a - R_pen_a) / R_pen_a)) )

-对护甲实际伤害量
D_to_armor = (D_past_shield - D_past_armor) × M_a × K_a × (1 - R_type_a) - I_a

-对核心实际伤害量
D_to_core = D_past_armor * max( 0.05, min(1, (P_a - R_core) / R_core) )
